# 慢慢弹 · 尤克里里可视化练习室

面向音乐初学者的中英文尤克里里练习网站，默认英文。保留课程导航、歌词、指法图和节拍格，将手部动作直接放在 Three.js 琴体上，跟随课程播放。

## 打开与运行

在线练习室：https://slow-strum.htrw24sw7s.workers.dev

[English](README.md) · [GitHub 源码](https://github.com/hx23840/slow-strum)

本机开发：http://127.0.0.1:5173/

双击 `start-practice.command`，或在本目录执行：

```sh
npm ci
npm run dev -- --port 5173
```

需要 Node.js 20.19+ 或 22.12+。首次安装依赖需要网络；安装后可在本机使用。项目无需账号、数据库或后端。

```sh
npm test
npm run build
npm run preview -- --port 5174
```

`dist/` 是可部署到静态服务器的构建文件。请通过 HTTP 服务器打开，不要直接双击 HTML 文件。线上使用 Cloudflare Workers 静态资源托管。

## 已完成的练习功能

- 11 节课程：认识琴弦、调弦、音阶、和弦转换、拨弦、分解、扫弦、慢速节奏、切音、Folk Rock 与综合弹唱。
- C、Am、F、G、G7 五个和弦，以及 C 大调八个音的按弦示意；空弦时手指抬开。
- 换和弦前先抬指再落下。Am→F 保持中指与支撑手位不变。
- 右手逐弦拨奏、向下/向上扫弦、留空摆动与轻触制音；动作、琴弦高亮、节拍格和声音由同一播放步骤驱动。
- 支持 40–120 BPM、四拍预备、暂停、单步、时间格定位、循环/单轮、单和弦练习和恢复自动跟随。
- 同向示意、左右手特写、侧面、旋转、缩放、放大演示区，以及可选按弦标记。
- 标准高 G 四弦参考音、节拍器、琴声开关、原创短句歌词与合成旋律提示。
- 学习进度在本机保存；新用户从第 1 节开始。正文保留本机中文字体、较大字号及窄屏排版。
- 手部资源载入失败时提供重试，仍可参考指法图；WebGL 不可用时保留指法和节拍练习。

原来的独立 G7 动作分解保留在 `/hand-study.html`，支持逐帧和 ¼/½/正常速度。

## 语言

- 右上角 `Language / 语言` 可选择 English 或简体中文；默认英文，不随浏览器语言自动切换。
- 课程说明、动态动作提示、调弦、指法图、无障碍标签和独立手部小样均支持两种语言。
- 选择保存在本机；`?lang=en` 或 `?lang=zh-CN` 可指定入口语言。
- 切换时暂停播放并重新载入对应内容，保留课程、当前半拍、速度、节奏型、声音设置和学习进度。手部小样保留动画位置和速度。
- 英文歌词为每句八个单音节词，与原有八个半拍及旋律音符对齐；中文保留原歌词。外链教学视频仍为中文，英文入口已标明。
- 英文文案集中在 `src/locales/en.js`，以中文源文案为键；`src/i18n.js` 处理语言选择、参数替换和模板文字翻译。新增语言需添加词典并注册语言选项。

## 怎么跟练

1. 从左侧选择课程，先用「听音调弦」对照四根弦。
2. 暂停看清琴上的手指；需要时切换「左手特写」或勾选「显示按弦位置」。
3. 点击「开始跟练」，跟着四拍预备进入练习。来不及时点「慢速」。
4. 点时间格或使用「下一半拍」拆开练；点击和弦按钮可以单独练一个和弦。
5. 弹唱课可打开旋律提示音，先哼唱，再跟着高亮歌词弹奏。
6. 「我练会了」记录你自己的学习进度，不是自动评分。

## 来源与边界

参考课程：[莉莉克丝 · 尤克里里初学者零基础入门教程](https://www.bilibili.com/video/BV1st411q7yc)。查看课程目录，并参考第 4 节约 02:15 的左手特写与第 5 节约 03:00 的右手特写。没有下载或重发布课程视频，也未进行视频动作捕捉。

本站的讲解、节奏和歌词练习独立制作，并非原课歌曲的完整曲谱或逐帧同步转制。琴声与旋律提示均为合成音，不包含人声演唱，也不使用麦克风检测音准。

手部采用固定指节长度的骨骼示意，沿用已确认的展示方向；它是方便跟练的同向映射视图，不是实际眼位相机。动作尚未经过真人教师逐项审核。手部来源为 MIT 许可的 WebXR generic-hand，版权声明见 `public/models/LICENSE.txt`。

## 主要文件

- `src/studio.js`：原练习室、课程和播放流程。
- `src/model.js`：Three.js 琴体、琴弦与演示区。
- `src/course-hands.js`：手部资源加载及播放联动。
- `src/hand-motion.js`：换指、扫弦和拨弦动作。
- `src/playing-view.js`：同向与特写镜头。
- `public/models/course-poses.json`：10 组左手按法及右手动作姿态。
- `src/data.js`、`src/audio.js`：课程数据和合成声音。
- `src/readability.css`、`src/i18n.css`：清新风格、阅读字号及语言排版。
- `src/i18n.js`、`src/locales/en.js`：语言工具和英文文案。
- `src/practice-session.js`：语言切换时校验并保留练习设置。
- `tests/i18n.test.mjs`：默认语言、翻译覆盖、参数一致性、歌词节拍及设置恢复检查。
- `tests/course.test.mjs`：动作覆盖、保留指、方向与音频时序检查。

运行 `npm test` 可检查动作、音频与翻译覆盖；运行网站不需要 Blender。
